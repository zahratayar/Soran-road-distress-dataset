# Soran Road Distress Dataset

A pavement distress image dataset collected from urban roads in Soran City, Kurdistan Region of Iraq, for automated pavement distress detection using YOLOv8.

## Dataset Description

This dataset was developed as part of a research study on pavement distress detection in Soran City. The images were collected from urban road sections and annotated according to pavement distress categories used in the study.

The dataset contains pavement images divided into three subsets:

- Training set
- Validation set
- Testing set
